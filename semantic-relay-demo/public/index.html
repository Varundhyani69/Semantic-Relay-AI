Demo Scenarios - Each Category Triggers Different AI Behavior:

  • 🎯 Electronics (High Confidence): Cohere similarity ~0.90+ → Skips Gemini (confident match)
  • 🤔 Clothing (Ambiguous): Cohere similarity ~0.70-0.84 → Invokes Gemini reasoning
  • 💾 Books (Pattern Cache): After first run → Uses cached pattern (instant, no AI)
  • ⚡ Kitchen (Deterministic): All filters identical → No AI needed (exact match)
